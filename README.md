# drumx

A desktop drum trainer for MIDI electronic drum kits, starting on macOS with a future Windows version in mind.

Planned: separate player profiles, configurable kit mapping, guided practice from fundamentals through rudiments and coordination, timing and velocity feedback, and saved progression across difficulty levels.

The project is currently in architecture exploration. There is no runnable application yet, and no stack has been committed to.
